# @whythis/vue

Development runtime for [WhyThis](https://github.com/ywkoh/whythis), a Vue 3 debugging tool. It displays the element picker, inspection drawer, recent observed changes, and Copy for AI action.

Most applications should install this package together with [`@whythis/vite`](https://www.npmjs.com/package/@whythis/vite), which instruments Vue single-file components and loads this runtime in development mode:

```bash
npm install -D @whythis/vite @whythis/vue
```

See the [`@whythis/vite` setup guide](https://www.npmjs.com/package/@whythis/vite) for Vite configuration and current limitations.
