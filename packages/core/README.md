# @whythis/core

Shared binding metadata, stable IDs, and registry types for [WhyThis](https://github.com/ywkoh/whythis), a Vue 3 development debugger.

This package is used by `@whythis/vite` and `@whythis/vue`. For application setup, install [`@whythis/vite` and `@whythis/vue`](https://www.npmjs.com/package/@whythis/vite).
